# Ordering the complexity classes

Implement `sort_by_growth(funcs)`. Each element is one of the labels

`"1"`, `"log n"`, `"n"`, `"n log n"`, `"n^2"`, `"n^3"`, `"2^n"`

Return them sorted from slowest-growing to fastest-growing. Duplicates are kept.
Anything outside the list above should raise `ValueError`.
